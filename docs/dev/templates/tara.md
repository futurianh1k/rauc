# 간이 TARA: <대상 시스템>

> **언제:** 외부와 통신하거나 신뢰 경계를 넘는 기능(OTA, 클라우드 연동, 진단, 무선)을 만들거나 바꿀 때 쓴다. **누가:** 오토모티브, MaaS, 임베디드.
>
> **주의:** ISO/SAE 21434 Clause 15를 참고한 1인용 간이 분석이다. UNECE R155 형식승인용 정식 TARA를 대신하지 않는다.
